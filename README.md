## ✨ Fitur Lengkap Aplikasi

- **⚡ Instant Continuous Scanner**: Pemindaian kilat tanpa jeda loading untuk barcode scanner fisik dan kamera HP.
- **🤖 Deteksi Cerdas Ekspedisi Otomatis**: Mendukung J&T, SPX (Shopee Xpress), SiCepat, JNE, Ninja Van, Anteraja, ID Express, Wahana, Lion Parcel, POS Indonesia, dan ekspedisi kustom lainnya.
- **📋 Berita Acara Serah Terima (BAST)**:
  - Penomoran otomatis BAST (`BAST-YYYYMMDD-XXXX`)
  - Pencatatan nama kurir, admin penerima, nomor polisi / kendaraan
  - Penghitungan koli otomatis
  - Klasifikasi kondisi paket: *Bagus/Normal, Rusak/Pecah, Sobek/Terbuka, Basah, Tertukar/Salah Kirim*
- **🖨️ Cetak & Export Manifest Lengkap**:
  - Format **Struk Thermal 80mm** (langsung cocok ke printer thermal kasir)
  - Format **Dokumen A4 Pas 1 Lembar**
  - Format **Dokumen A4 Rinci Lengkap**
  - Export **PDF Resmi** bertanda tangan
  - Export **CSV Spreadsheet (Excel)**
  - Tombol 1-klik salin seluruh nomor resi
- **📱 PWA & Dukungan Offline Penuh**:
  - Tersedia tombol "Install di Layar Utama HP / Android"
  - Tetap berfungsi lancar meski koneksi internet gudang terputus.
- **☁️ Sinkronisasi Data**: Opsi sinkronisasi ke Google Drive atau Firebase Cloud Firestore.

## 🛠️ Menjalankan di Komputer Lokal (Opsional)

Jika ingin menjalankan server di komputer lokal:

```bash

npm install

# 2. Jalankan dev server
npm run dev
```

Buka `http://localhost:3000` di browser Anda.
